# הסקריפטים והמקורות של ובלכתך בדרך עברו ל־book-sources

הממיר `ובלכתך_בדרך.py`, `rename.py`, הבדיקות וקובצי המקור (`שונות/`: קובצי ה־XML, `fix_tnc.xml` וכלי הניתוח) נמצאים כעת ב־[Otzaria/book-sources](https://github.com/Otzaria/book-sources/tree/main/OnYourWayToOtzaria/סקריפטים), בהעתקה זהה בבתים.

הריצו את הממיר מתוך תיקיית הכלים החדשה עם `REPO_ROOT` המצביע ל־checkout של **otzaria-library**, כדי שיחולו `post_convert_fixes.py` ו־`post_convert_fixes.tsv` שכאן; ראו [הוראות ההרצה וההגירה](https://github.com/Otzaria/book-sources/blob/main/docs/MIGRATION_ONYOURWAY.md).

`ספרים/` ו־`post_convert_fixes.tsv` נשארים כאן. האריזה, הקישורים והמטא־דאטה לא השתנו.

# הר שפר — מהדורת תשפ"ה (רבי שמואל פירר, אב"ד קראס)

ספר "הר שפר" על מסכת הוריות, בצירוף חידושי תורה על סוגיות הש"ס ומדרשים, מהדורה חדשה (תשפ"ה) בעריכת
מרדכי פירר (בן נינו של המחבר). נבנה מקובץ ה־PDF שיצא מ־InDesign (308 עמודים, יש שכבת טקסט — בלי OCR).
הספר + `הערות על הר שפר` + קובץ קישורים `footnotes`:

```
MoreBooks/ספרים/אוצריא/תלמוד בבלי/אחרונים/הר שפר.txt
MoreBooks/ספרים/אוצריא/תלמוד בבלי/אחרונים/הערות על הר שפר.txt
MoreBooks/links/הר שפר_links.json
```

התיקייה הזו **אינה נארזת** לשחרור. המקור: `extraBooks/הר שפר/ספר הר שפר.pdf`.

## החלפת עותק דיקטה

באוצריא היה כבר "הר שפר" מדיקטה (`DictaToOtzaria/ערוך/…/תלמוד בבלי/אחרונים/הר שפר.txt`, 317 שורות, הוריות
בלבד, מהדפוס הראשון תרפ"ג). הוולידטור (`validate_fordb_book_names.py`) אוסר שני קבצים נארזים עם אותו שם,
וגם בנייה עם שני עותקים הייתה דורסת ב־`BOOK_ROOTS` ממילא — לכן עותק דיקטה הועבר ל־
`extraBooks/דיקטה ערוך/יש במור בוקס/הר שפר.txt` (המוסכמה של המאגר לספר ערוך שנמצא כבר ב־MoreBooks;
ראו `DictaToOtzaria/סקריפטים/README.md`). הרשומות הקיימות של "הר שפר" נשארו: `metadata.json`,
`ForDB/book_info.csv` (דור "אחרונים"), `ForDB/all_metadata.json` (שנת דפוס 1923 וכו'; רק `Sourcefolder`
עודכן מ־`Dicta` ל־`MoreBooks`) — ונוספה שורת תיאור ב־`ForDB/sefaria_metadata_changes.csv`.

## הרצה

```bash
cd "MoreBooks/סקריפטים/הר שפר - סקריפטים"
SRC="../../../extraBooks/הר שפר/ספר הר שפר.pdf"; OUT=/tmp/harshefer; mkdir -p $OUT
python3 -I extract_pdf.py "$SRC" $OUT/events.json      # דורש pdftotext (poppler) ו־pymupdf
python3 -I assemble_book.py $OUT/events.json $OUT      # הר שפר.txt, הערות על הר שפר.txt, הר שפר_links.json
python3 -I verify_conservation.py "$SRC" $OUT          # שימור מילים מול שני מקורות
python3 -I verify_merge_gate.py --books $OUT --links "$OUT/הר שפר_links.json"
python3 install.py --src $OUT                          # יבשה; --apply כותב לריפו
```

| סקריפט | תפקיד |
| --- | --- |
| `extract_pdf.py` | PDF → אירועים (כותרת / דף / פסקה / הערה) לפי גופן, גודל ומיקום |
| `assemble_book.py` | אירועים → ספר, ספר הערות, קישורים; התאמת סמן↔הערה, רמות כותרת |
| `copyright.txt`, `copyright_line.py` | נוסח זכויות היוצרים (שורה אחת) והשורה שנבנית ממנו; `assemble_book.py` ו־`verify_conservation.py` מייבאים אותה |
| `verify_conservation.py` | multiset של כל מילה בפלט מול ה־PDF (mupdf ו־poppler) |
| `verify_merge_gate.py` | פורט של חוזה המיזוג של SeforimLibrary (כל הערה נשתלת במקום הסמן) |
| `install.py` | העתקה לריפו ועדכון המרשמים (בלי לכפול זהות ב־`book_info.csv`) |

## איך חולץ הטקסט (למה לא `pdftotext` ולא mupdf לבד)

ה־PDF שומר טקסט עברי בסדר חזותי. mupdf נותן סדר לוגי טוב למילים אבל **מבלבל סימני פיסוק וקווים מפרידים**
(`ששלי - שלה` יצא `.- ששלי`, `(-הערת` יצא `-(`) ושומר לפעמים בספאן אחד שני קטעים מרוחקים באותה שורה (וכך
סמן הערה נפל במקום שגוי). poppler (`pdftotext -bbox`) מציב נכון את הפיסוק, אבל נותן מילים הפוכות
תו־תו ללא מידע על סגנון. לכן: **הטקסט והסדר מ־poppler** (כל מילה מתהפכת, מלבד סמני הערה ותוויות שמגיעים
ממנו כבר בסדר לוגי), **הסגנון (בולד / קטן / עילי) מ־mupdf** לפי התו הקרוב ביותר, והשורה נבנית מהמילים.
ספרות (`עמ' 35)`) מטופלות כריצה שאינה מתהפכת.

## מה הוקלד ביד (לא בשכבת הטקסט)

- הערה בכותרת המשנה של הנספח (`(מתוך ספר אגרות ותולדות מהר"ם שפירא מלובלין, עמ' 80)`) — הספרות והסוגריים
  יוצאים מבולבלים מהחילוץ.
- **נוסח האגרת בעמוד 308** (תעתיק מודפס שבתחתית העמוד הוא תמונה): הוקלד מהתמונה. אין OCR עברי במכונה —
  כדאי עין נוספת, בעיקר על "לעקד הספרים", "בציון המצינת", "וועבער מקארטשין". את כתב היד עצמו לא תיעתקנו.

## מה לא נכנס לספר

- **שער, הקדשה ותולדות חיי רבנו** (עמ' 1, 5, 11–18, עם 25 הערות) — הוסרו לבקשת המשתמש ב־2026-10-08;
  הם ב־PDF, ואפשר להחזיר ע"י הוצאת העמודים מ־`SKIP` ב־`extract_pdf.py` וטיפול בכותרות ב־`assemble_book.py`.
- הכריכה, עמוד הזכויות (טלפון ומייל פרטיים של המהדיר), תמונת שער המהדורה הראשונה (עמ' 3), תוכן העניינים
  המודפס (אוצריא בונה בעצמה), דפי הפרדה, עמודים ריקים ותמונת כתב־היד.
- **הקדמת המוציא לאור של המהדורה הראשונה (תרפ"ג, יעקב צבי ארנברג)** קיימת רק בעותק דיקטה שהועבר ל־
  `extraBooks/דיקטה ערוך/יש במור בוקס/הר שפר.txt` (שורות 5–12); היא אינה במהדורת תשפ"ה.

## מגבלות ידועות

- כותרת דף שנופלת באמצע פסקה במקור מפצלת את הפסקה לשתי שורות (כותרת הדף ביניהן) — כך נקבע גבול הדף.
- בעמוד 304 המקור כותב מרכאות חכמיות (`”`, `’`); הומרו ל־`"` ו־`'` כבשאר הספר.
- **זכויות:** העמוד הפנימי נושא "כל הזכויות שמורות" (מרדכי פירר, תשפ"ה). נדרש אישור המהדיר לפני פרסום.
- **שורת זכויות יוצרים (שורה 3 של הספר):** `כל הזכויות שמורות למכון הלכה סדורה, אין להעתיק ושכפל בכל צורה שהיא`, באותו סימון
  אפור וקטן של שאר ספרי הספרייה (`<span style="color:Gray;"><small><small>…</small></small></span>`). הנוסח נשמר ב־`copyright.txt`
  ו־`copyright_line.py` בונה ממנו את השורה. בגלל השורה הזו `line_index_1` ב־`הר שפר_links.json` גדול ב־1 מהמספר שהיה בלעדיה
  (קובץ ההערות לא השתנה, ולכן `line_index_2` נשאר). שינוי הנוסח או הסרתו מחייבים הרצה מחדש של `assemble_book.py`,
  התקנה, וחישוב מחדש של `manual_links_lineage.json` (ר' לעיל).

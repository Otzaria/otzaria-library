# אוצר ההלכה — צינור ההמרה

המרת חמשת כרכי "אוצר ההלכה" על שולחן ערוך אורח חיים (הלכות שבת), מהדורת מכון
"איש מצליח", מקובצי PDF לספרי אוצריא מקושרים.

התיקייה הזו **אינה נארזת** לשחרור (רק `MoreBooks/ספרים/אוצריא` ו־`MoreBooks/links`
נארזים).

## הרצה

```bash
python3 build_all.py --out /tmp/out          # מפענח את ה־PDF ובונה את הקבצים
python3 merge_contract.py /tmp/out           # חובה: בלי זה המיזוג ייכשל בשקט
python3 qa.py /tmp/out                       # מספור, הערות, תקינות מבנה וקישורים
python3 install.py --src /tmp/out --apply    # כותב למאגר (בלי --apply = הרצה יבשה)
```

מקור ה־PDF: `~/Downloads/אוצר ההלכה שבת {א,ג,ד,ה,ו}.pdf` (כרך ב אינו קיים).
תלות יחידה: `pymupdf`.

## מה נוצר לכל כרך

| קובץ | תוכן |
| --- | --- |
| `אוצר ההלכה … חלק X.txt` | הספר. שורה = ערך. סימון הערה בגוף: `<sup>N</sup>` |
| `הערות על אוצר ההלכה … חלק X.txt` | ההערות. שורה = הערה, בצורה `<sup>N</sup> טקסט` |
| `אוצר ההלכה … חלק X_links.json` | **קובץ אחד, שני סוגים**: `source` לשולחן ערוך, `footnotes` לספר ההערות |

ספר ההערות נפרד רק בקלט: `HearotCompanionMerge` ב־SeforimLibrary ממזג אותו חזרה
לשורות הבסיס כהערות משובצות ומדכא אותו כספר עצמאי. המיזוג הוא הכל־או־כלום —
שורה אחת בספר ההערות שאינה כותרת ואינה מקושרת, או הערה עם `<i>`, מבטלת את הכרך
כולו בשקט. לכן `merge_contract.py` חייב לרוץ לפני ההתקנה.

הקישור לשולחן ערוך נשען על `ref_2` ולא על `line_index_2`: `ManualLinksRefresh`
מחשב מחדש את מספרי השורות מול ייצוא ספריא העדכני לפני כל בנייה.

## הקבצים

| קובץ | תפקיד |
| --- | --- |
| `otzar_extract.py` | לב העניין. הגופנים הם קדם־יוניקוד, וה־ToUnicode ממפה אותיות עבריות לתווים לטיניים. לומד מפענח לכל משפחת גופן מתוך התפלגות האותיות של הספר עצמו — בלי טבלה קשיחה — משחזר גליפים שמאבדים בדרך, ומסדר את התווים לסדר לוגי |
| `structure.py` | ריהוט העמוד: זיהוי רצועות, שתי עמודות, כותרות סימן/סעיף, מילואים, וחלוקה לערכים לפי מספריהם |
| `notes.py` | רצועת "הערות וציונים": כיוון הקריאה נקבע לפי איזו קריאה מפיקה רצף מספרים עולה יותר |
| `render.py` | ערך → שורת אוצריא; ההערות נאספות החוצה |
| `build_all.py` | מרכיב את שני הספרים וקובץ הקישורים |
| `merge_contract.py` | מאמת מול חוזה המיזוג של ה־DB |
| `qa.py` | רצפי מספור, פתרון הערות, תקינות מבנה, תקפות קישורים |
| `install.py` | מעתיק למאגר ורושם בשלושת המרשמים: `metadata.json` (ממנו נגזר המחבר), `ForDB/all_metadata.json` ו־`ForDB/generations.csv`. כל אחד בפורמט שלו — כתיבה בפורמט אחר מחליפה כל שורה בקובץ |
| `solve_sub.py` | פותר צופן־החלפה לגופן בודד שמיפויו תמורה שרירותית. אינו מופעל בברירת מחדל (`OTZAR_SOLVE=1`) |

## מה שהמספור מאמת

לספר שני מספורים בלתי־תלויים — מספרי הערכים בגימטריה ומספרי ההערות. שניהם משמשים
כ־checksum: שבר ברצף פירושו שגיאת פענוח, ולא טעות דפוס. חריגים אמיתיים שנמצאו
בדפוס: מספר 156 מופיע פעמיים בכרך ד, ומדורי מילואים מתחילים מספור מחדש.

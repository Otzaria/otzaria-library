# שו"ת משנה הלכות — צינור ההמרה

17 כרכי שו"ת משנה הלכות לרבי מנשה קליין, כפי שהם באתר tshuvos.com, מתוקנים
מול ה־PDF המודפס שהאתר מגיש (`https://www.tshuvos.com/pdf/mishnehalochosN.pdf`).

התיקייה הזו **אינה נארזת** לשחרור.

## הרצה

```bash
python3 build_books.py --src <תיקיית הגריפה> --build . --out /tmp/mh
python3 qa_struct.py /tmp/mh                          # validate_book + שאריות + היררכיה
python3 qa_preserve.py <תיקיית הגריפה> /tmp/mh        # שימור טקסט, טוקן־טוקן
python3 install.py --src /tmp/mh --apply              # בלי --apply = הרצה יבשה
```

הגריפה (`משנה הלכות חלק X.txt`) נוצרה ב־`otzaria/tshuvos.py` שבמכונת ה־Windows
(`C:\Users\win\Downloads\books`). כל דף באתר = `<h2>` + שורה לכל `<p>`.

## הערות למי שיחזור לכאן

- האתר מצהיר 275 סימנים בחלק ח; בדפוס 247. הדפים 248–275 ריקים בשרת.
- ביב, האתר כותב "סימן תג חסר מטעות הדפוס" — ב־PDF הוא קיים (6 שורות). ההערה נמחקה.
- ביז, בדפוס אין כותרת קיז (116 ו־117 מודפסים יחד); נשמר כסימן נפרד כמו באתר,
  והמספור שאחריו תואם לדפוס.
- `י` 2496: `ב"ב?` תוקן ל־`נ"ב` לפי ה־PDF — תיקון נוסח, לא רק אות.
- גריפה מחדש **ממכונה מסוננת (NetFree/אתרוג)** מוחקת פסקאות ודפים שלמים בשקט.
  אין להשתמש בה לאימות.

`analysis/` — הסקריפטים שהפיקו את שלושת קובצי ה־JSON, מול ה־PDF ודפי האתר.
הם רצו בסביבת עבודה זמנית (נתיבים קשיחים) ונשמרים לתיעוד בלבד.

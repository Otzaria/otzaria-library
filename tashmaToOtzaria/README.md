# מקורות תא שמע עברו ל־book-sources

קובצי JSON גולמיים, ממירים וחומרי הביקורת נמצאים ב־[Otzaria/book-sources](https://github.com/Otzaria/book-sources/tree/main/tashmaToOtzaria/סקריפטים).

ראו [הוראות ההגירה וההרצה](https://github.com/Otzaria/book-sources/blob/main/docs/MIGRATION_TASHMA.md). הריצו משם עם `REPO_ROOT` המצביע ל־checkout של הספרייה הזאת, ותיקיית staging מפורשת לפלט טקסט.

`ספרים/אוצריא`, `links` ו־`post_convert_fixes.tsv` נשארים כאן ומשמשים לאריזה ולהמרות. עותקי התיקונים בריפו המקורות הם תיעוד של נקודת ההעתקה בלבד; הממירים קוראים את התיקונים העדכניים מהספרייה.

כלי המרת הקישורים משנה את קובץ הקישורים שנמסר לו; השתמשו בעותק עבודה ובדקו את השינוי לפני commit. אין צורך להפיק מחדש ספרים או קישורים בגלל העברת המקורות.

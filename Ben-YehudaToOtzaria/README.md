# כלי בן־יהודה עברו ל־book-sources

הממיר (`ben_y.py`), מודול הסימון, פיצול ההערות, הבדיקות, רשימות המחברים והקטלוג נמצאים כעת ב־[Otzaria/book-sources](https://github.com/Otzaria/book-sources/tree/main/Ben-YehudaToOtzaria/סקריפטים).

הריצו את הממיר מתוך תיקיית הכלים החדשה עם `REPO_ROOT` המצביע ל־checkout של **otzaria-library**; ראו [הוראות ההרצה וההגירה](https://github.com/Otzaria/book-sources/blob/main/docs/MIGRATION_BEN_YEHUDA.md).

`ספרים/` (כולל `לא ממויין`), `links/` ו־`post_convert_fixes.tsv` נשארים כאן. ספרים חדשים, ספרי הערות וקישורים נכתבים לנתיבים הקיימים, והתיקונים נקראים מכאן; אין להריץ את הממיר כש־REPO_ROOT מצביע לריפו המקורות.

# כלי הספרייה הלאומית עברו ל־book-sources

הסקריפטים, המיפויים ובדיקות הנרמול נמצאים כעת ב־[Otzaria/book-sources](https://github.com/Otzaria/book-sources/tree/main/National-LibraryToOtzaria/סקריפטים).

הריצו את הממיר מתוך תיקיית הכלים החדשה עם `REPO_ROOT` המצביע ל־checkout של **otzaria-library**; ראו [הוראות ההרצה וההגירה](https://github.com/Otzaria/book-sources/blob/main/docs/MIGRATION_NATIONAL_LIBRARY.md).

`ספרים/`, `links/`, `post_convert_fixes.tsv` ו־`otzaria_metadata.json` נשארים כאן. הפלט, התיקונים, הקישורים והאריזה ממשיכים להשתמש בנתיבים הקיימים; אין להריץ את הממיר כש־REPO_ROOT מצביע לריפו המקורות.

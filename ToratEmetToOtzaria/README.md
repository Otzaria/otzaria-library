# כלי תורת אמת עברו ל־book-sources

הסקריפטים (`te_convert`, `te_reapply`, `te_tidy`, `te_restore_notes`, `te_books.json`, `beyom hashabat/manipulate.py`
ועוד), קובצי העבודה הישנים והבדיקות נמצאים כעת ב־[Otzaria/book-sources](https://github.com/Otzaria/book-sources/tree/main/ToratEmetToOtzaria/סקריפטים),
יחד עם קובצי המקור של תורת אמת (`ToratEmetToOtzaria/ספרים` שם).

הריצו את הכלים מתוך book-sources עם `REPO_ROOT` המצביע ל־checkout של **otzaria-library**; ראו
[הוראות ההרצה וההגירה](https://github.com/Otzaria/book-sources/blob/main/docs/MIGRATION_TORAT_EMET.md).
בלי `REPO_ROOT` תקין הכלים נכשלים לפני שהם קוראים או כותבים.

`ספרים/`, `links/` ו־`post_convert_fixes.tsv` נשארים כאן. הספרים, התיקונים, הקישורים והאריזה ממשיכים להשתמש
בנתיבים הקיימים.

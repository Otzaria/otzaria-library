# סקריפטי דיקטה → אוצריא

```
books.json של דיקטה ─► OCRDataURL (zip של דפי HTML) ─► dicta_convert.py ─► dicta_clean.py ─► לא ערוך/
                                                                                     │
                                  עריכת ספרים/ (כלי GUI) + הסקיל dicta-book-pipeline ─┴─► ערוך/
```

| קובץ | תפקיד |
| --- | --- |
| `dicta_convert.py` | ההמרה: דפי ה־HTML של דיקטה → טקסט אוצריא. מודול טהור, בלי רשת. |
| `dicta_clean.py` | ניקוי דטרמיניסטי אחרי ההמרה, ובסופו איחוד רצפי `<b>` (`merge_bold_runs`). |
| `ניקוי_דטרמיניסטי.py` | שם הפקודה הוותיק — עוטף את `dicta_clean.py`. |
| `dicta_sync.py` | **הזרימה החודשית** (`.github/workflows/dicta-import.yml`): books.json + HEAD → תכנית → הורדה → המרה → שער → מיקום → כתיבה → מצב. ר' "ייבוא רציף" למטה. |
| `dicta_state.json` | **מקור האמת**: רשומה לכל `fileName` של דיקטה — מה דיקטה מפרסמת, מה ה־zip (MD5 = ETag), איפה הספר במאגר ולמה. |
| `dicta_pages.json` | hash של אותיות כל דף, לכל ספר (לזיהוי דפים שנוספו/השתנו). |
| `sefaria_fp.dat` | טביעות 8-grams מדוגמות (1/256) של 5,821 ספרי ספריא מתוך seforim.db (5.9MB), לזיהוי ספר דיקטה שכבר נמצא בספריא בשם אחר. בנייה מחדש: `fp-index --sefaria-db …/seforim.db`. |
| `dicta_placement_table.json` | נתיבי הקטגוריות של ספריא (מ־seforim.db) — המדפים שאליהם `dicta_place` ממקם. |
| `dicta_place.py` / `dicta_gate.py` / `dicta_replay.py` / `dicta_fp.py` | מיקום בעץ ספריא · שער איכות · העברת תיקוני OCR מההיסטוריה · טביעות טקסט. |
| `עריכת ספרים/dicta_edit_core.py` | הלוגיקה של כל כלי העריכה (כותרות, דף/עמוד, הדגשה, בדיקות). ה־GUI־ים קוראים לו. |
| `tests/` | בדיקות (unittest, רצות גם ב־pytest), בלי רשת ובלי תלויות. |

## ייבוא רציף (`dicta_sync.py`)

```bash
python3 dicta_sync.py detect --out plan.json [--max-books 40]   # books.json + HEAD לכל zip, בלי הורדות
python3 dicta_sync.py import --plan plan.json [--dry-run DIR] [--no-promote]
python3 dicta_sync.py reconcile          # ספר שאדם העביר מ"ערוך/ספרים/לא ממויין" אל "אוצריא/" → מרשמים
python3 dicta_sync.py sort --accept <fileName>   # git mv למיקום המוצע + מרשמים
python3 dicta_sync.py report             # ספירה לפי סטטוס
```

**לאן הולך ספר:**

| שער האיכות | מיקום | יעד | מרשמים |
| --- | --- | --- | --- |
| עובר | בטוח (סדרה קיימת / רמב"ם / שו"ע — 97.7% ב־leave-one-out) | `ערוך/ספרים/אוצריא/<נתיב>` | metadata.json, ForDB/all_metadata.json, all_metadata_with_file_paths.json, book_info.csv |
| עובר | לא בטוח | `ערוך/ספרים/לא ממויין/<קטגוריה של דיקטה>/` (לא נארז) | אין, עד `sort`/`reconcile` |
| נכשל | כל מיקום | `לא ערוך/ספרים/אוצריא/<נתיב>` או `…/אוצריא/לא ממויין/<קטגוריה>/` | אין |

* **כפילות תוכן, גם בשם אחר**: הטקסט החדש מושווה לכל הספרים הנארזים (אינדקס טביעות שנבנה/מתעדכן בכל ריצה
  לפי blob sha: `fp-index --library`, ב־CI ב־actions/cache) ולספרי ספריא (`sefaria_fp.dat`), באותם ספים כמו
  ב־bootstrap: ≥50% מהספר בספר ערוך של דיקטה → כבר עובד, לא נכתב כלום; ≥50% בספר נארז אחר / בספריא →
  `extraBooks/דיקטה/`; חפיפה כוללת ≥20% → נכנס עם `reason: partial overlap`. מועמדים מהספרייה נבדקים
  שוב מול הטקסט המלא בדגימת ה־bootstrap. על 1,007 הספרים זה משחזר את כל 175 הכפילויות ואת 737 הערוכים.
* שם זהה לספר ספריא/נארז: חפיפה ≥50% → `extraBooks/דיקטה/` (לא נארז); בלי חפיפה → `לא ערוך` וסטטוס `needs-human`.
* שורת המחבר (שורה 2) נכתבת בכתיב הקנוני של `metadata.json` כשהאדם כבר קיים שם; אחרת — כתיב דיקטה, ודיווח.
* ספר ערוך קיים **לא נדרס לעולם**; דפים חדשים מדווחים (הכנסה ידנית + `linkshift`).
* ספר גולמי שה־zip שלו השתנה, או שחסרים בו דפים (`verify-raw`), מומר מחדש, והתיקונים שנעשו בו ב־git
  מועברים ל־המרה החדשה ברמת מילה (`dicta_replay`; זוג "מהדורה אחרת" ודפוס המוני כמו `סי→סימן` נחסמים).
* שינויי שם/מחבר/קטגוריה אצל דיקטה — דיווח בלבד (`dicta_changes` במצב). מחברים לא מסונכרנים אוטומטית.
* `ערוך/ספרים/לא ממויין/` מחוץ ל־`BOOK_ROOTS`/`PACKAGED_PREFIXES` — בדיקת `PackagingContractTest` נופלת אם זה ישתנה.

**השער** (`dicta_gate.py`) דורש מבנה של ספר ערוך: כותרות משנה בצפיפות ≥2 ל־10k מילים, אין קטע בלי כותרת
שגדול מ־20% מהספר, ≥90% מהכותרות קצרות, ≤5% שורות קטועות, ≥70% מהשורות מסתיימות בפיסוק, תגים מאוזנים,
ואף מילה מה־zip לא אבדה. עובר ב־60% מהספרים הערוכים במאגר, ב־0–4.6% מהגולמיים, וב־16% מפלט הממיר הנוכחי
(166 מ־1,007 ספרים). ברירת המחדל ב־workflow: ריצה שמוסיפה ספר לספרייה נפתחת כ־PR.

**bootstrap** (פעם אחת, מקומית, ~560MB zips): `python3 dicta_sync.py bootstrap --zip-cache DIR --seforim-db …/seforim.db`
ואחריו `verify-raw --zip-cache DIR`.

## מה התגים של דיקטה אומרים

כל דף ב־zip הוא רצף `<span class="…">טקסט</span>`. המשמעות נקבעה מקוד האתר
`library.dicta.org.il` (הקובץ `assets/index-*.js`), מקובצי ה־JSON שהאתר טוען לכל דף
(`files.dicta.org.il/library-1-0/<book>/<page>.zip`, שדות `markedParagraph`, `display[].bold/heading`,
`flagged`), ומהשוואה בין הפורמט הישן והחדש של אותם ספרים:

| מחלקה | משמעות | הראיה |
| --- | --- | --- |
| `marked-paragraph` | **תחילת פסקה — הסימן היחיד לפסקה.** | האתר מצייר `<br><br>` לפני הטוקן; ייצוא הטקסט שלהם כותב `\r\r` לפניו. |
| `bold` | הדגשה בלבד, **לא** תחילת פסקה. | `font-bold`. בפורמט החדש גם הרווח בין שתי מילים של אותו רצף מסומן `bold`. |
| `heading` | אות גדולה (`text-5xl font-bold`) — סגנון, לא בלוק. בפועל: כותרות מודפסות. | ב־85% מהמקרים בספרים הערוכים הרצף הפך לשורת כותרת (h2 53%, h3 47%). |
| `flagged` | מילה ש־OCR לא בטוח בה (האתר צובע אפור). 5–10% מהמילים. | `text-gray-500` כש־`showOCRFlaggedWords`. |
| `edited` | מילה שתויגה/תוקנה ידנית אצל דיקטה. מידע בלבד. | `edited` כש־`showManualTagging`. |
| `user-star` | סימון ממשק (273 מופעים בכל הספרייה). מתעלמים. | |

**שני פורמטים.** כל 1,007 הספרים ב־`books.json` הנוכחי הם בפורמט `library-1-0` (החדש); הישן
קיים רק ב־URL־ים הישנים (`old books.json`). `detect_format` מבחין לבד:

- **חדש (`word`)**: `marked-paragraph` רק על המילה הראשונה של הפסקה; אין `\n` בטקסט.
  בקובצי ה־HTML (לא ב־JSON) הסימון מופיע לפעמים על רווח — מתעלמים ממנו.
- **ישן (`line`)**: `marked-paragraph` על כל מילות **השורה המודפסת הראשונה** של הפסקה, ו־`\n` בסוף
  אותה שורה. פסקה חדשה = תחילת רצף מסומן, או `\n` שאחריו הרצף ממשיך (פסקה בת שורה אחת ואחריה
  פסקה נוספת). `\n` שאחריו טקסט לא מסומן הוא סתם סוף שורה.

61 מתוך 569 ספרים בפורמט החדש **אין בהם סימון פסקה בכלל** (למשל חידושי הר"ן על מגילה) — שם
הפיצול נשען רק על סימני הפיסוק (למטה).

`textFileURL` (ייצוא טקסט) לא משמש: אותן מילים בדיוק, אבל בלי הדגשה וכותרות, `:` של סוף פסקה
עובר לתחילת השורה הבאה (באג כיווניות), ובחלק מהספרים אין בו ירידות שורה בכלל.

## איך הממיר מפצל שורות

1. פסקה של דיקטה (לפי הפורמט) = שורה חדשה. פסקה ממשיכה מעבר לגבול דף.
2. רצף `heading` = שורה משלו, `<h2>…</h2>` (בלי `<big>`, בלי `<b>`). הרמה קבועה; את הרמה האמיתית
   קובעת עבודת הכותרות.
3. בתוך פסקה: אחרי מילה שמסתיימת ב־`:` (סוף עניין), אלא אם היא מודגשת והבאה לא
   (`<b>מחצלת:</b> עשויה…`). ולפני רצף מודגש שבא אחרי מילה לא מודגשת המסתיימת ב־`.`.
4. הדגשה לבדה **לא** פותחת שורה (הממיר הישן פתח שורה לפני כל מילה מודגשת).
5. `<b>` סמוכים מאוחדים בסוף השרשרת (`merge_bold_runs`), חוץ מסמני מקור:
   `<b>תוס'</b> <b>ד"ה ולא</b>` נשארים שניים (גם רש"י / ד"ה / בא"ד / גמ' / מתני').

כל כלל נמדד מול 42 ספרים ערוכים (ר' "מדדים"). כללים שנבדקו ונדחו: שבירה לפני כל רצף מודגש
(56% דיוק), שבירה אחרי `)`/`]` שלפני מודגש (58%), שבירה אחרי תווית "סימן X" (80%, אבל זו
עבודת `create-headers`).

## API לשימוש ה־workflow

```python
import dicta_convert as DC
res = DC.convert_zip_final(zip_bytes_or_path, book_record, page_order=None)
res.text      # הספר (<h1>, מחבר, גוף), מסתיים ב־\n
res.fmt       # "word" / "line"
res.flagged   # [{"line", "word", "text", "page", "edited"}] — לקובץ לוואי, לא לספר
res.stats     # pages / lines / headings / words / flagged
DC.build_metadata(book_record)   # printYear "1925-1931" → 1925, בלי קריסה
```

- `page_order`: רשימת `fileName` מ־`https://files.dicta.org.il/library-1-0/<fileName>/pages.json`
  (הסדר של האתר). בלעדיה — מיון מספרי לפי המספר האחרון לפני `__ocr_data.html`.
- `ConvertOptions(heading_tag=None)` — כותרות דיקטה כשורת טקסט רגילה.
- `DC.finalize_text(text)` — ניקוי + איחוד `<b>` לטקסט קיים.
- שורת פקודה: `python3 dicta_convert.py BOOK.zip -o out.txt [--meta rec.json] [--flagged f.json] [--raw]`.

## ניקוי (`dicta_clean.py` / `ניקוי_דטרמיניסטי.py`)

ברירת מחדל: `G` (תווים בלתי־נראים, רווחים, NFC), `E` (`<b>` באמצע מילה), `F` (`ע"א`/`ע"ב`
יתום), כללי ה־OCR `P`,`S`,`R`,`T` (למטה), ואחרון `M` (איחוד רצפי `<b>`). כבויים: `B` (מיזוג שורה מודגשת לקודמת — לקבצים של הממיר
הישן בלבד; על פלט החדש מוריד recall) ו־`H` (הסרת `<b>` ממספר גימטריה בודד — צומצם למספרים עם
גרש/גרשיים; הגרסה הקודמת הסירה הדגשה מ־`שם`, `ר'`, `כסף`).

### כללי OCR (`P`, `S`, `R`, `T` — פעילים, לפני `M`)

טעויות OCR שחוזרות בספרייה. כל כלל הוא פונקציה טהורה לשורה (`fn(line, log=None)`), והרשימה
`dicta_clean.OCR_RULES` (לפי הסדר) / `apply_ocr_rules(line, log=...)` מאפשרת להריץ אותם שורה־שורה
על ספרים קיימים. שורת `<h1>` (שם הספר) לא נוגעים. דיוק על 25 מופעים אקראיים בכל כלל מתוך
`ערוך/ספרים/אוצריא` (ספטמבר 2026): P 556 מופעים, S 362, R 318, T 121 — 25/25 בכל כלל.

| כלל | מה | מתי **לא** |
| --- | --- | --- |
| `P` | `בשבת ודף כ"ג)` → `בשבת (דף כ"ג)` — ו' שהיא "(" לפני דף / ד' / סי' / סימן / סעיף / עמוד / פרק / פ' / שם | בתוך סוגריים פתוחים; אין `)` עד 30 תווים; אחרי ההפניה לא מספר (`וד' הגמ'`, `ושם יהיו`); סוף משפט באמצע; תווית רשימה `ו)`; מיד אחרי הפניה אחרת (`דף י"ב ודף ל"ג)`); שני מועמדים לאותו `)` |
| `S` | אות סופית באמצע מילה: `דאםור` → `דאסור`, `ןזה` → `וזה`, `המיםשל` → `המים של` | המילה מוכרת במילון; המועמד פחות מ־100 מופעים; קריאה מתחרה סבירה (`מםני`: ממני/מפני, `ןכר`: נכר/זכר); פיצול עם חלק של אות אחת או שתי אותיות שאינן מילה (`בגיטןין`); `לכןף` (סימן דבוק); צמוד לגרש, ניקוד או תג באמצע מילה |
| `R` | `הרמב"מ` → `הרמב"ם` (גם `״`) | — |
| `T` | `התוס` / `ובתוס` / `תוס` → עם גרש (לפי הגרש הנפוץ בשורה) | `ביתוס`, `אל תוס`, `תוס 'ד"ה`, `תוס.'`, כשכבר יש גרש |

מילון השכיחות של `S`: `dicta_word_freq.tsv.gz` (≈2MB, מילה↹מספר, מילים עם ≥3 מופעים בכל
`BOOK_ROOTS`, בלי ניקוד), נטען בעצלות בשימוש הראשון. בנייה מחדש:
`python3 dicta_clean.py --build-word-freq <שורש המאגר>`. בלי הקובץ `S` לא משנה דבר.

```bash
python3 ניקוי_דטרמיניסטי.py FILE...              # G,E,F,P,S,R,T,M
```

## כלי העריכה (`עריכת ספרים/`)

השמות נשארו. כולם קוראים ל־`dicta_edit_core.py` (בלי pyluach/gematriapy/bs4). מה תוקן:

| כלי | באג |
| --- | --- |
| `יצירת_כותרות_לעמוד_ב.py` | "עבודה זרה…" זוהה כ־ע"ב (`<h3>עמוד ב</h3>` + "ודה זרה"); נמחקו כל `' . , : ) ]` בשורה; "גמ'" שוכפל. עכשיו: `ע` + גרש/גרשיים + גבול מילה, ופיסוק לא נמחק. |
| `הוספת_מספר_עמוד_בכותרת_הדף.py` | `ע"?[א-ב]` אכל את "עב" של "עבודה". |
| `הגדרת כותרות לאוצריא.PY` | "דף ב." ו"דף ב:" הפכו שניהם ל"דף ב"; "פרק ב דברכות" הפך לכותרת. |
| `בדיקת_תגים.py` | "גירסא 2" השוותה תמיד ל־index+2. עכשיו כלי אחד, עם תיבת "מצב ש"ס" שחלה רק על רמת `דף`; בודק גם תגים פתוחים/סגורים וטקסט ליד כותרת. |
| `הדגשת_מילה_ראשונה_וניקוד_בסוף_קטע.py` | שתי הפעולות יחד איבדו את סימן הסוף; התחיל מהשורה הרביעית; כפתור ההרצה לא ראה את הקובץ שנבחר. |
| `נקודותיים_ורווח_גירסא_2.py` | שבר אחרי כל `:` — גם בכותרות, בתוך `<b>` ואחרי `וז"ל:`. |
| `אותיות בודדות עם כמה סימונים בו זמנית.py` | מצב "מודגש" לא עבד לעולם (`startswith("<b>") and startswith("</b>")`). עכשיו רק מספור ברצף (תיבת "רק ברצף"), כך ש־ר'/ה'/"שם." לא הופכים לכותרת. |

נמחקו ככפולים: `בדיקת תגים גירסא 2.PY` ו־`בדיקת-תגים גירסא 2 ישן.py` (הוחלפו ב־`בדיקת_תגים.py`), `אותיות_בודדות_גירסא_2.py` (תת־קבוצה של "אותיות בודדות עם כמה סימונים בו זמנית"), ו־`remove_sp.py` (סקריפט חד־פעמי של בן־יהודה, לא קשור לדיקטה).

`readme.md` שבתיקייה מתאר את הכלים; הגרסה המתוחזקת במקביל היא github.com/Otzaria/EditingDictaBooks.
